Crie o gastos-cli: uma ferramenta de linha de comando em Node.js, sem dependências externas, para registrar gastos pessoais. Comandos: `add <valor> <categoria> [descricao]`, `list` (lista os gastos), `total [categoria]` (soma, opcionalmente por categoria) e `export <arquivo.csv>`. Os dados ficam num arquivo JSON local. Entrada inválida (valor não numérico, comando desconhecido) imprime mensagem de erro e sai com código diferente de 0. Testes com o runner nativo `node --test`. README curto com exemplos. No máximo 8 tarefas.
